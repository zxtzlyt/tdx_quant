## P0 高优先级 —— 回测数字敢不敢信 + 每天愿不愿意用

### 1. 送转股口径修复(最实质的正确性缺口)
- **现状**:`divid_factors` 只取 Bonus 现金派息列,Type=11 扩缩股 Bonus 恒为 0(`tq_client.py` docstring 已注明)。分红再投模型只补现金股息、不补送转股本——"10送10"标的除权日价格腰斩、股本翻倍,模型里股本不动也没现金补投,收益严重低估。茅台类纯派息股掩盖了问题,全市场回测选到高送转股即错。
- **动手**:divid_factors 扩展返回送转比例(走 `call()` 原始接口取 Type=11 行);`indicators.total_return_with_dividends` 与 backtest 收益链加股本调整分支;找一只知名高送转股做真值锚定用例。

### 2. 回测加交易成本与卖出条件
- **现状**:零手续费 + 固定持有 N 日,超额收益天然虚高;无法表达止损。
- **动手**:`backtest.run` 加佣金/印花税/滑点参数(双边);卖出条件做成与选股同型的回调(拿 asof 窗口返回 bool);报告加分年度收益表与逐日资金曲线——现在只有汇总统计,看不出策略何时失效。

### 3. kcache 增量更新
- **现状**:首建后只能整体重建,每日盘后想回测就得重拉全历史。
- **动手**:加 sync 入口——读缓存末日期,从次日起增量拉取追加(lday 二进制天然支持追加)。

### 4. 盘后一条龙配方
- **现状**:数据下载 → lday 合并 → kcache 增量 → vipdoc 分钟归档,四步独立脚本,是每天实际主链路。
- **动手**:`examples/daily_pipeline.py` 串起来,带各步成功/跳过的日志汇总;配 Windows 任务计划。

## P1 中优先级 —— 能力扩展

### 5. 指标库扩展
RSI / KDJ / BOLL / ATR + 量价类(换手、振幅)。纯标准库递推,成本低,直接放大回测策略的选股表达空间。

### 6. 分笔数据解析器
DataTool 管道已把分笔补到本地(盘后通道收官那次),但无解析器、无消费者。分笔是主力/散户行为分析的基础维度,也是唯一只能靠本机通道拿的数据——管道通了没消费等于白攒。

### 7. 分钟归档格式优化
全市场 CSV 体积与读回速度会先成为瓶颈。最小改动 gzip(标准库,不破零依赖红线);进阶自研 lday 风格二进制。

### 8. 财务衍生比率层
cw_fields 已锚定校准、gpcw 有原始 FN,但缺现成 ROE/毛利率/负债率计算层,pick_fundamental 用户要自己推公式。加一个薄 ratios 模块。

### 9. 因子评测框架
把 backtest 泛化一步:给定因子值序列 → IC / RankIC、分五层分层回测。是"选股策略回测"的上位替代——判断一个想法值不值得写成策略,先跑因子。

### 10. 涨停/连板复盘统计
从日线/盘中快照统计涨停梯队、炸板率、封板金额。数据全有,缺的只是统计口径;短线复盘高频需求,也是盘后一条龙的天然延伸。

## P2 低优先级 / 待条件

### 11. 板块文件本地解析
客户端 T0002 的板块/自定义股文件(`block_*.dat`)直接读:板块成分、自选股离线可查;pick_technical 写回的板块可反向读出,做信号持久化。

### 12. 扩展市场行情封装
TQ 通道本身支持 ETF/债券/港美股等扩展品种,封装一层市场前缀映射,ETF 轮动、股债平衡策略就有数据可用。

### 13. F10 本地缓存解析(先探可行性)
通达信有 F10 资料的本地缓存目录,股东户数/股本变动等栏目若能解析,等于多一套免费基本面数据。

### 14. 事件研究
财报披露日(gpcw 里有)、除息日前后 N 日的超额收益漂移,验证"财报后买入"这类套路有没有效。

### 15. 组合层工具
波动率倒数、行业分散等仓位方案 + 相关性矩阵;回测输出从"单股持有 N 日"升级到"组合净值曲线 + 夏普/卡玛"。

### 16. 配方库扩充
缩量回调、N字反包、板块动量轮动等模板——pick + backtest 骨架已就位,每条只是换个条件函数。

### 17. 盘中盯盘脚本
`snapshot_batch` 已可批量拉五档,包一个轮询循环(价格/涨速阈值 → 提示音/弹窗),零依赖盯盘器。

### 18. 数据体检命令
`python -m tdx_local` 一条命令报告 kcache/分钟归档覆盖情况:哪些代码缺哪些日期段、缓存几时该增量。归档攒几个月后是刚需。

### 19. 结果 HTML 报告
回测/选股结果直接生成一份 HTML(纯标准库拼接),带净值曲线与持仓明细,比裸 CSV 舒服。

### 20. numpy 可选加速
指标与回测在全市场 5000 只维度下还能再快一个量级;做成 `tdx_quant[numpy]` 可选依赖,红线:没装也能跑。

### 21. 公式 DLL 测试台架
DLL 公式通道已全通,配一个批量喂行情、比对新旧公式结果的工具,调试公式会顺手很多。
