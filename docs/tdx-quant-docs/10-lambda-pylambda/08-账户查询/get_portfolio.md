# 获取组合get_portfolio

###  取当前账户快照 get_portfolio

```python
get_portfolio(refresh=True)
```

用途：

  * `get_portfolio(refresh=True)` 返回当前 `Portfolio` 快照；默认会先刷新资金和持仓。
